# Fun Toys

The public cabinet for eighteen small open-source toys.

Live: https://fun-toys-alpha.vercel.app  
Repo: https://github.com/syedahmad0786/fun-toys

Static HTML. No build step. Walnut/brass museum cabinet with 3D shelf cards, grain, and per-toy marks from `fun-toys-kit`. Each card links to a separate live app and GitHub repo.
